# LayerX コーポレートサイト (layerx.co.jp) デザイン分析

## 1. サイト概要

- **URL**: https://layerx.co.jp/
- **企業ミッション**: 「すべての経済活動を、デジタル化する。」
- **リニューアル**: 2023年11月（SHIFTBRAIN Inc. + PARK Co., Ltd. 制作）
- **デザインコンセプト**: 「社会にX番目のレイヤーをどんどん足す、作っていく」
- **情報設計方針**: わかりやすく、透明性が高い

---

| ページ | URL | 概要 |

## 3. トップページ レイアウト構成

### 3.1 ヘッダー（Header）
- **高さ**: 約 64〜80px
- **構成**: ロゴ（左） + グローバルナビ（中央/右） + CTA（右端）
- **ナビ項目**: 私たちについて / 事業内容 / ニュース / 採用情報 / お問い合わせ
- **スマホ**: ハンバーガーメニュー化
- **特徴**: スクロール時に固定（sticky）、背景白 or 透過

### 3.2 ヒーローセクション（Hero）
- **横幅**: 100vw（フルワイド）
- **縦幅**: 100vh or 約 600〜800px
- **比率**: 約 16:9〜16:7（デスクトップ）
- **内容**: ミッションコピー「すべての経済活動を、デジタル化する。」
- **背景**: ロゴモーション／アニメーション（レイヤーが積み重なるビジュアル）
- **タイポグラフィ**: 大見出し（40〜64px）

### 3.3 ミッションセクション
- **横幅**: コンテナ幅（max 1200px）、中央寄せ
- **縦幅**: コンテンツ依存（約 400〜600px）
- **内容**: 副文「⼈類の未来をより良くする。そのために私たちは、テクノロジーの可能性を探求し、経済活動における複雑で⼤きな課題に挑む。」
- **デザイン**: 大きめテキスト、余白重視

### 3.4 事業紹介セクション（Business）
- **レイアウト**: カード型（3カラムグリッド → スマホで1カラム）
- **横幅**: コンテナ幅（max 1200px）
- **カード構成**:
  - **バクラク**: AI SaaS（経費精算、法人カード、請求書、勤怠管理）
  - **三井物産デジタル・アセットマネジメント**: Fintech事業
  - **Ai Workforce**: AIプラットフォーム
- **各カード**: アイコン/画像 + タイトル + 概要テキスト + リンク

### 3.5 ニュースセクション
- **レイアウト**: リスト形式
- **横幅**: コンテナ幅（max 1200px）
- **各アイテム**: 日付 + カテゴリ + タイトル
- **表示件数**: 3〜5件 + 「もっと見る」ボタン

### 3.6 会社文化・人物セクション
- **内容**: 社員の写真、誠実さ・信頼性・対話的でオープンな社風
- **レイアウト**: 写真グリッド or フルワイド画像
- **デザイン意図**: 人とのつながりを大切にする文化の表現

### 3.7 CTA（Call to Action）セクション
- **内容**: 採用情報への導線、お問い合わせ
- **レイアウト**: フルワイド背景 + 中央寄せテキスト + ボタン

### 3.8 フッター（Footer）
- **横幅**: 100%
- **高さ**: 約 200〜400px
- **構成**:
  - ロゴ
  - サイトマップリンク（私たちについて / 事業内容 / ニュース / 採用 / お問い合わせ）
  - SNSリンク（X, note, LinkedIn 等）
  - コピーライト: © LayerX Inc.
  - プライバシーポリシー等の法的リンク

## 5. レスポンシブデザイン

### 5.1 ブレークポイント

| 名前 | 幅 | 対象デバイス |
|------|------|-------------|
| Mobile | 〜767px | スマートフォン |
| Tablet | 768px〜1023px | タブレット |
| Desktop | 1024px〜1279px | 小型デスクトップ |
| Wide | 1280px〜 | 大型デスクトップ |

### 5.2 コンテナ幅

| ブレークポイント | コンテナ幅 | パディング |
|-----------------|-----------|-----------|
| Mobile | 100% | 20px 左右 |
| Tablet | 100% | 40px 左右 |
| Desktop | 1080px | auto（中央寄せ） |
| Wide | 1200px | auto（中央寄せ） |

### 5.3 レスポンシブ挙動

- **ヘッダー**: PC=横並びナビ → SP=ハンバーガーメニュー（768px境界）
- **ヒーロー**: PC=100vh → SP=auto（テキストサイズ縮小）
- **事業カード**: PC=3カラム → Tablet=2カラム → SP=1カラム
- **ニュース**: レイアウト変化なし（リスト形式は全幅で維持）
- **フッター**: PC=横並び → SP=縦積み
- **画像**: `object-fit: cover` + srcset/sizes で最適化

## 6. インタラクション・アニメーション

- **ヒーロー**: ロゴモーション（レイヤーが積み重なるアニメーション）
- **スクロール**: フェードイン / スライドアップアニメーション（Intersection Observer）
- **ホバー**: カードのシャドウ・スケール変化、リンクの色変化
- **ページ遷移**: スムーズなトランジション
- **ヘッダー**: スクロール時の背景色変化（透過→白）

## 7. 技術スタック（推定）

- **フォント配信**: Google Fonts（Noto Sans JP）
