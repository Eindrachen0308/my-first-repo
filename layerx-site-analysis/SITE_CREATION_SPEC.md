## サイト構造テンプレート（LayerXスタイル準拠）

### ページ構成

```
/ (トップページ)
├── /about (ミッション・ビジョン)
│   └── /about/company (会社概要)
├── /business (事業内容)
├── /news (ニュース・お知らせ)
├── /careers (採用情報) ※外部リンク可
├── /contact (お問い合わせ)
└── /privacy (プライバシーポリシー)
```

### トップページ セクション構成

| 順序 | セクション | 横幅 | 縦幅 | レイアウト |
|------|----------|------|------|----------|
| 1 | ヘッダー | 100% | 64-72px (sticky) | ロゴ左 + ナビ中央/右 + CTAボタン右端 |
| 2 | ヒーロー | 100vw | 100vh (100dvh) | 全画面、中央寄せテキスト、暗い背景 |
| 3 | ミッション | max 1200px | auto | 中央寄せ、大きなテキスト、上下余白80-120px |
| 4 | 事業紹介 | max 1200px | auto | 3カラムカード、灰色背景 |
| 5 | ニュース | max 1200px | auto | リスト形式、日付+カテゴリ+タイトル |
| 6 | カルチャー/写真 | max 1200px | auto | 写真3カラムグリッド、灰色背景 |
| 7 | CTA | 100% | auto | 全幅ダーク背景、中央テキスト+2ボタン |
| 8 | フッター | 100% | auto | ダーク背景、4カラムナビ+SNS+法的リンク |

### レスポンシブ ブレークポイント

| 名前 | ブレークポイント | グリッド | コンテナ padding |
|------|---------------|---------|----------------|
| Mobile (SP) | 〜767px | 1カラム | 20px |
| Tablet | 768px〜1023px | 2カラム | 40px |
| Desktop | 1024px〜1279px | 3カラム | 32px (max 1080px) |
| Wide | 1280px〜 | 3-4カラム | auto (max 1200px) |

### レスポンシブ挙動ルール

- **ヘッダー**: PC→横並びナビ / SP→ハンバーガーメニュー（境界: 768px）
- **ヒーロー**: PC→100vh / SP→auto + フォントサイズ縮小 (clamp)
- **事業カード**: PC→3列 / Tablet→2列 / SP→1列
- **ニュースリスト**: PC→横並び(日付+タイトル) / SP→縦積み
- **CTA**: PC→ボタン横並び / SP→ボタン縦積み
- **フッター**: PC→4カラム横並び / SP→縦積み
- **画像**: object-fit: cover + loading="lazy"

### タイポグラフィ体系

| 用途 | PC | SP | Weight | 実装 |
|------|----|----|--------|------|
| ヒーロー見出し | 48-64px | 28-36px | 700 | clamp(2rem, 5vw, 4rem) |
| セクション見出し | 32-40px | 24-28px | 700 | clamp(1.5rem, 3vw, 2.5rem) |
| カード見出し | 20-24px | 18-20px | 600 | clamp(1.125rem, 2vw, 1.5rem) |
| 本文 | 16px | 14-15px | 400 | clamp(0.875rem, 1.2vw, 1rem) |
| キャプション | 12-14px | 12px | 400 | clamp(0.75rem, 1vw, 0.875rem) |

### スペーシング体系

| 名前 | 値 | 用途 |
|------|------|------|
| xs | 4px | 最小余白 |
| sm | 8px | アイコンとテキスト間 |
| md | 16px | 要素間の基本余白 |
| lg | 24px | カード内パディング |
| xl | 40px | セクション内余白 |
| 2xl | 64px | セクション間余白（SP） |
| 3xl | 80px | セクション間余白（PC） |
| 4xl | 120px | セクション間余白（Wide） |

### インタラクション仕様

| 要素 | アクション | 効果 |
|------|----------|------|
| ヘッダー | スクロール | 背景色変化（透過→白）、border表示 |
| カード | ホバー | translateY(-4px) + shadow-lg |
| リンク | ホバー | 下線アニメーション（width: 0→100%） |
| ボタン | ホバー | translateY(-1px) + shadow-md + 色変化 |
| セクション | スクロールイン | fade-up (opacity 0→1, translateY 24px→0) |
| モバイルメニュー | トグル | translateX(100%→0) スライドイン |

## 技術スタック（推奨）

| カテゴリ | 技術 | 理由 |
|---------|------|------|
| フレームワーク | Next.js (App Router) | SSG/SSR対応、SEO最適化 |
| スタイリング | CSS Modules or Tailwind CSS | コンポーネント単位の管理 |
| 言語 | TypeScript | 型安全性 |
| フォント | Google Fonts | Noto Sans JP + Inter |
| アニメーション | Intersection Observer API | 軽量、ネイティブ |
| デプロイ | Vercel | Next.jsとの親和性 |
