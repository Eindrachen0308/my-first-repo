# 家族旅行プランナー GAS セットアップガイド

毎朝8時・夜20時半に、関東圏内の家族旅行スポット＆イベント情報を自動収集し、Gmailの下書きに保存するGoogle Apps Scriptです。

---

## セットアップ手順

### Step 1: Google Apps Script プロジェクトを作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「家族旅行プランナー」に変更

### Step 2: コードをコピー

1. デフォルトの `コード.gs` の中身を削除し、`Code.gs` の内容を貼り付け
2. 左メニューの「＋」→「スクリプト」で新しいファイルを追加し、`Setup` と名前を付けて `Setup.gs` の内容を貼り付け

### Step 3: appsscript.json を編集

1. 左メニュー「プロジェクトの設定」（歯車アイコン）をクリック
2. 「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻り、`appsscript.json` ファイルを開いて内容を貼り付け

### Step 4: メールアドレスを設定

`Code.gs` の先頭付近にある以下の箇所を、ご自身のメールアドレスに変更：

```javascript
EMAIL_TO: 'your-email@gmail.com',  // ← ここを変更
```

または、スクリプトエディタ上部の関数選択で `setupEmail` を選び、実行：

```javascript
setupEmail('your-real-email@gmail.com');
```

### Step 5: 初回セットアップを実行

1. スクリプトエディタ上部の関数選択で **`setupAll`** を選択
2. 「実行」をクリック
3. 初回はGoogleの認証画面が表示されるので、以下を許可：
   - Gmail（下書き作成のため）
   - Google スプレッドシート（データ保存のため）
   - 外部サービスへの接続（RSS取得のため）
4. 実行ログに「セットアップ完了」と表示されれば成功

## 動作の仕組み

```
毎朝8:00 / 夜20:30（自動トリガー）
    ↓
① RSSフィードからイベント・スポット情報を取得
② (オプション) Google Custom Search APIで追加検索
    ↓
③ 家族の好み（アンパンマン、サンリオ、恐竜、パウパトなど）で
   関連度スコアリング＆フィルタリング
    ↓
④ 過去に送信済みの情報を自動除外（スプレッドシートの送信履歴を参照）
    ↓
⑤ 上位5件を選んでGmail下書きに保存
⑥ 全データをスプレッドシートに蓄積
```

---

## 作成されるスプレッドシートの構成

| シート名 | 内容 |
|---------|------|
| スポット一覧 | 収集した全スポット情報（訪問済みフラグ、メモ欄付き） |
| 送信履歴 | 過去にメール下書きに含めた情報（重複除外に使用） |
| イベント情報 | 期間限定イベントの情報 |

## オプション: Google Custom Search API の設定

RSSだけでは情報量が限られるため、Google Custom Search API を設定するとより多くの情報を取得できます。

### 手順

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. Custom Search API を有効化
3. APIキーを取得
4. [Programmable Search Engine](https://programmablesearchengine.google.com/) でカスタム検索エンジンを作成
   - 検索対象サイト: `iko-yo.net`, `jalan.net`, `rurubu.jp`, `walkerplus.com` など
5. GASエディタで以下を実行：

```javascript
setupSearchAPI('YOUR_API_KEY', 'YOUR_SEARCH_ENGINE_ID');
```

> 無料枠: 1日100クエリまで無料

## 管理コマンド一覧

スクリプトエディタの関数選択から実行できます：

| 関数 | 説明 |
|------|------|
| `setupAll()` | 初回セットアップ（スプレッドシート作成＋トリガー設定） |
| `testRun()` | 手動テスト実行 |
| `morningRun()` | 朝の実行を手動で実行 |
| `eveningRun()` | 夜の実行を手動で実行 |
| `showCurrentConfig()` | 現在の設定を確認 |
| `setupTriggers()` | トリガーを再設定 |
| `clearAllTriggers()` | すべてのトリガーを削除 |
| `resetAll()` | データをリセット |

## トラブルシューティング

### 「承認が必要です」と表示される
→ Googleアカウントのアクセス許可が必要です。「権限を確認」→「許可」をクリック

### 「このアプリは確認されていません」と表示される
→ 「詳細」→「〇〇（安全ではないページ）に移動」をクリック（自分で作ったスクリプトなので安全です）

### RSSフィードの取得に失敗する
→ サイト側の仕様変更の可能性があります。`CONFIG.SOURCES` のURLを最新のものに更新してください

### 下書きが作成されない
→ `showCurrentConfig()` でメールアドレスが正しく設定されているか確認してください
