# ブランドスタイルガイド v0.1 (テンプレート)

本ドキュメントは、ビデオポッドキャストから派生するすべての成果物 (動画 / ショート / SNS 図解 / note 記事 / 将来的に Kindle) が一貫したブランド体験になるための基準書です。

> **v0.1 の位置づけ**: 各項目は「定義すべき枠」を先に示したテンプレートです。`【要記入】` 欄は事業側の意思決定が必要な箇所。合意のうえで v1.0 に昇格させます。

## 1. ブランドエッセンス

### 1.1 番組コンセプト
【要記入】 番組が何を、誰に、どんな価値で届けるか (1 文で)

例) "〇〇業界の現場の意思決定を、当事者の肉声でデフォルメせずに届ける対話番組"

### 1.2 キーワード (想起したい印象)
【要記入】 5 個以内。SNS の文体やサムネのトーンに直結

例) 誠実 / 現場感 / 踏み込む / データで語る / 余白を残す

### 1.3 避けたい印象
例) 扇動的 / 安請け合い / 過度な断定 / 内輪ノリ

## 3. ビジュアルアイデンティティ

### 3.1 ロゴ
- ロゴ原本 (SVG / PNG): 【要提供】
- 最小サイズ: 横 120px
- クリアスペース: ロゴ高さの 1/4 以上
- NG 使用: 単色反転 / 傾斜 / 装飾追加

### 3.2 カラー
| 用途 | カラー |
|---|---|
| Primary | 【要記入】 HEX: #______ |
| Secondary | 【要記入】 HEX: #______ |
| Accent | 【要記入】 HEX: #______ |
| Text (濃) | #1A1A1A 目安 |
| Text (薄) | #6B6B6B 目安 |
| Background | #FFFFFF / #F7F7F7 |

### 3.3 タイポグラフィ
| 用途 | フォント |
|---|---|
| 見出し (日本語) | 【要記入】 例) Noto Sans JP Bold |
| 本文 (日本語) | 【要記入】 例) Noto Sans JP Regular |
| 見出し (英字) | 【要記入】 例) Inter Semibold |
| 字幕 | 【要記入】 太字+縁取り必須 |

### 3.4 サムネイル
- アスペクト比: 16:9 (YouTube) / 1:1 (Insta Feed) / 9:16 (Shorts/Reels/TikTok)
- 文字数目安: 16:9 で 最大 20 字 / 9:16 で 最大 15 字
- 必須要素: 番組ロゴ (右上/左下) + 回タイトル + 出演者サムネ (任意)
- 共通テンプレ: Canva に 3 パターン用意 (P0 で発注)

## 4. 声のトーン (Voice & Tone)

### 4.1 基本方針
- **Voice** (常に一貫): 落ち着いた、具体、対等な立場で語る
- **Tone** (場面で調整): SNS では軽く、note ではやや硬め、Kindle では最もフォーマル

### 4.2 文末表現
| チャネル | 文末 |
|---|---|
| X | です/ます体 or 体言止め混在 |
| Instagram | です/ます体 |
| note | です/ます体 (「〜だ/である」は避ける) |
| YouTube タイトル | 体言止め or 疑問形 |
| 字幕 | 口語そのまま。フィラーのみ除去 |

### 4.3 使わない表現
- 過度な煽り: 「絶対」「神」「ヤバい」「最強」
- 業界内輪語 (初出時の読者に通じないもの) は必ず初出定義
- 断定の根拠なき評価: 「トップ企業」「圧倒的シェア」(数値・出典必須)
- 他社をくさす表現

### 4.4 積極的に使う表現
- 当事者の実例・固有名詞 (社内情報は後述のマスキング規定に従う)
- 数字は必ず出典と期日を添える
- 異論・反論を紹介する余白

## 5. 禁則事項 (情報統制)

自動ルールチェックが検出する項目を以下に定義します。詳細実装は `config/brand-rules.sample.yaml`。

### 5.1 Block (強制停止)
- 未発表製品・機能・提携先の名称
- 現在係争中の案件への言及
- 従業員個人の実名 (肩書き置換が原則)
- 顧客の特定につながる情報 (非公開事例)
- 未開示の財務情報・業績予想
- 採用に関わる応募者個別情報

### 5.2 Warn (人間レビュー)
- 数字を含む主張 (「X% 増」「N 社導入」)
- 競合他社名の言及
- 法令・規制への言及
- 医療・金融などの専門助言的表現
- 断定的な予測

### 5.3 Auto Fix (自動置換)
- 表記ゆれ (例: 生成 AI ↔ Generative AI)
- 商標記号 (® / ™) の付与・削除
- 全角/半角の統一

## 6. 出演者の扱い

| 項目 | ルール |
|---|---|
| 呼称 | `Speakers` DB の Display Name に従う |
| 肩書き表記 | 「〇〇 / △△社 CEO」の順で、初出時のみフルで表記 |
| 声サンプル | 話者分離のために収録前に 30 秒以上の独立音声を取得 |
| 発言の引用 | 該当タイムコードを Notion に記録 (後から訂正可能に) |
| 発言撤回 | 収録後 24 時間以内は無条件で削除可 |

## 7. 引用と出典

- 事実主張には必ず出典 URL を付記
- 図表引用時は出典を画像内に明記 (「出典: 〇〇」フォント 14pt 以上)
- 翻訳引用時は原文 URL も併記
- 画像素材は Artlist / Unsplash など商用可のみ

## 8. チャネル別ガイドライン

### 8.1 YouTube (本編)
- 冒頭 15 秒でテーマ提示
- 概要欄: タイトル / 出演者 / チャプター / 関連リンク / ハッシュタグ
- チャプター必須 (5 分以内の粒度)
- エンドスクリーン: 次回予告 + チャンネル登録

### 8.2 YouTube Shorts / Reels / TikTok (ショート)
- 尺: 30-60 秒
- 冒頭 3 秒で「掴み」(LLM が問いかけ or 結論先出しを生成)
- 字幕必須 (音なし視聴対応)
- 縦型 9:16 固定、重要情報は画面中央 60% に収める

### 8.3 Instagram (Feed 画像)
- 1 投稿 = カルーセル 5-10 枚
- 1 枚目: 質問形のキャッチ
- 2-N 枚目: 要点 1 つずつ
- 最終枚: 出典 + 本編動画への誘導

### 8.4 X
- 1 投稿 = 1 要点
- スレッド投稿を活用 (3-7 ツイート)
- 末尾に本編リンク + ハッシュタグ

### 8.5 note
- 見出し構造: H2 で章立て / H3 で節
- 冒頭に要約 3 行
- 文字数目安: 3,000-6,000 字
- 末尾に出演者プロフィール + 番組フォローリンク

### 8.6 (将来) Kindle
- 複数回分を「章」として再構成
- 各章の冒頭に「この章で学べること」
- 巻末に全出典一覧
